# АЙРИС · сайт iriseye.ru

Сайт компании «АЙРИС»: монтаж видеонаблюдения, СКУД, охранной и пожарной сигнализации и систем оповещения в Нижнем Новгороде и области.

## Что внутри

- **Главная (`index.php`)**:
  - киношная заставка с логотипом;
  - ролик остановками: одно движение колёсика, свайп или стрелка проигрывают его до следующей плашки, а назад он едет так же плавно;
  - семь плашек поверх ролика: на компьютере сбоку, на телефоне снизу;
  - ниже: услуги, калькулятор, работы, отзывы, вопросы и форма заявки;
  - фон под роликом: символы плывут вниз, лучи идут вверх, частицы тянутся к курсору (Particle Drift с 21st.dev, перенесён на чистый JS).
- **Админка (`/admin`)**:
  - заявки: статусы, поиск, выгрузка в Excel;
  - правка контактов, цен калькулятора, фото объектов, отзывов и вопросов;
  - документы и реквизиты;
  - уведомления в Telegram.
- **Документы по 152-ФЗ**: политика (`/privacy`) и отдельное согласие (`/consent`), у каждого текста свои редакции.

Чистые PHP 8.1+, SQLite и ванильный JS. Без фреймворков и без сборки.

## Ролик

В `assets/video` по две записи на каждый экран: прямая и такая же задом наперёд. Браузеры не умеют проигрывать видео назад, поэтому при прокрутке вверх играет вторая запись.

| Файл | Где | Размер кадра |
|---|---|---|
| `hero-d.mp4`, `hero-d-rev.mp4` | компьютер | 1920×1080, 24 кадра/с (вертикальный ролик расширен до 16:9 в Higgsfield) |
| `hero-m.mp4`, `hero-m-rev.mp4` | телефон | 720×1280, 30 кадров/с |

Секунды остановок и сторона каждой плашки заданы в начале раздела «ГЕРОЙ» в `assets/js/site.js`: у горизонтального и вертикального ролика они свои.

Если кадр на остановке мягкий (камера в этот момент движется), остановке можно дать резкий снимок того же кадра: поле `still` у остановки, файл в `assets/img/still-*.webp`. Снимок проявляется поверх паузы и гаснет, когда ролик поехал. Сейчас так сделан оповещатель на телефоне: кадр 190 улучшен в Higgsfield (GPT Image 2.5), подогнан по положению и цвету к кадру видео. Если ролик поменяется, запись задом наперёд собирается так:

```bash
ffmpeg -i hero-d.mp4 -an -vf reverse -c:v libx264 -preset slow -crf 26 -g 6 -pix_fmt yuv420p -movflags +faststart hero-d-rev.mp4
```

## Требования к хостингу

PHP 8.1 или новее с расширениями pdo_sqlite, gd, curl, mbstring, fileinfo.

По 152-ФЗ база с заявками россиян должна храниться на сервере в России, поэтому подойдёт, например, Beget или Timeweb.

## Где лежат данные

База, секретный ключ, сессии и загруженные через админку фото хранятся в папке `iriseye-data` на уровень выше сайта. Поэтому повторная выкладка их не стирает. Если туда писать нельзя, сайт использует `data/` внутри себя и закрывает её через `.htaccess`. В репозиторий данные не попадают (см. `.gitignore`).

## Запуск на своём компьютере

```bash
php -S 127.0.0.1:8080 -t . dev/router.php
```

Потом откройте http://127.0.0.1:8080

## Первый вход в админку

Ссылку первого запуска с одноразовым ключом печатает служебная команда:

```bash
php lib/cli.php setup-link https://iriseye.ru
```

По ссылке владелец сам задаёт логин и пароль. Если пароль забыли:

```bash
php lib/cli.php reset-admin
```

Потом получите новую ссылку той же первой командой.

## Копия для GitHub Pages

GitHub Pages не запускает PHP. Поэтому в корне лежит статическая копия: `index.html`, `privacy.html`, `consent.html` и пустой `.nojekyll`. Её собирает команда:

```bash
php lib/cli.php build-static
```

После правок в `index.php`, текстах или ценах по умолчанию копию нужно собрать заново и закоммитить.

Чем копия отличается от сайта на хостинге:

- админки и базы нет, цены и тексты берутся из `lib/defaults.php`;
- форма не отправляет заявку на сервер, а предлагает отправить её в WhatsApp или Telegram готовым текстом;
- копия закрыта от поисковиков (noindex), чтобы не спорить с iriseye.ru.

На хостинге с PHP адреса `.html` открывают живые страницы, копия там не мешает.

## Перед запуском

1. В админке, в разделе «Документы и реквизиты», заполните ИП или ООО, ИНН, ОГРН и email. Без реквизитов документы неполные.
2. В разделе «Уведомления» подключите Telegram-бота.
3. В разделе «Цены калькулятора» впишите цены АПС и СОУЭ. Пока там 0, калькулятор пишет «по смете».
4. Тексты политики и согласия стоит показать юристу: это заготовка.

Папка `dev/` нужна только для локального запуска, на хостинге она закрыта.
